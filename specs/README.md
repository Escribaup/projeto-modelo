# Especificações

Aqui ficam as especificações das tarefas **grandes**, uma pasta por funcionalidade:

```
specs/
└── 001-nome-curto/
    ├── especificacao.md   ← o quê e por quê (requisitos e critérios de aceite)
    ├── plano.md           ← como vamos construir
    └── tarefas.md         ← lista de tarefas, marcadas conforme ficam prontas
```

Para criar uma, digite `/especificar` no Claude Code e descreva a ideia. O Claude faz perguntas, escreve a especificação com você e só começa a construir depois da sua aprovação.

Tarefas pequenas e médias não precisam de especificação. O Guia vivo ajuda a escolher o tamanho certo.
